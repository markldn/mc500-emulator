# System disk images (not included)

The MC-500 loads its operating software from floppy disk. The disk images are
copyrighted by Roland and are **not** distributed with this repository. Image
your own disks (737280-byte raw 720K images, 80 tracks x 2 sides x 9 x 512)
and place them here.

The web UI expects these filenames:

| File                | Software                          |
|---------------------|-----------------------------------|
| `MRC-500-v110.dsk`  | MRC-500 v1.10 recorder (default)  |
| `Super-MRC-v2.dsk`  | Super-MRC v2                      |
| `MRC-300-v1.dsk`    | MRC-300 v1.0                      |
| `MRB-500.dsk`       | MRB-500 bulk librarian            |
| `MRP-500.dsk`       | MRP-500 performance               |
