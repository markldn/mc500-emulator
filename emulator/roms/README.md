# ROM images (not included)

The boot ROM images are copyrighted by Roland and are **not** distributed with
this repository. Dump them from your own hardware and place them here.

The web UI expects these filenames (8KB raw dumps of the boot ROM):

| File                  | Machine            |
|-----------------------|--------------------|
| `MC-500-v2.2.bin`     | MC-500, ROM v2.2 (recommended, default) |
| `MC-500-v2.3.bin`     | MC-500, ROM v2.3   |
| `MC-500II-v1.0.4.bin` | MC-500 MkII v1.0.4 |
